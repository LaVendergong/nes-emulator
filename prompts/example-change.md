# 填好的示例：日常变更

把下面整段发给 AI。这是 `04-change` 填完后的样子。

```
这是一次增量变更。按最小合入 diff 执行。

## 变更
- 意图：模拟器时钟在暂停后恢复，不得跳到墙钟时间
- 现象或需求：暂停 10 秒再继续，游戏内时间快进了 10 秒
- 建议落点（可被你推翻）：时钟/调度相关模块
- 禁止事项：不要改渲染循环，不要引入新的时间库

## 动手前先写四行
1. 意图
2. 模块（改 / 不改）
3. 风险（可能破坏的不变量）
4. 验证（命令或检查）

## 执行
- 只改与意图直接相关的代码。
- 发现必须扩大范围：停止，说明原因，等待确认。
- 修 bug：先复现，再改，再用同一路径验证。
- 不要顺手格式化无关文件，不要升级无关依赖。
- 行为有变就更新地图或 ADR 里对应的那一句。
```
