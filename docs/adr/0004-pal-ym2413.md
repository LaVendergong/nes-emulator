# ADR 0004: PAL 与完整 YM2413

- 状态：已接受
- 日期：2026-08-23

## 背景

ADR 0002 只做 NTSC。用户点名 PAL 软件标题、VRC7 要完整 OPLL、Namco 175/340。继续拒 PAL 会挡住标了 PAL 的盘；继续用两算子近似会挡住 Lagrange Point 音色。

## 决策

- **同一套周期核，三套制式**：iNES/NES 2.0 头选择。NTSC：1 CPU = 3 PPU dots，262 线。PAL：5 CPU = 16 dots，312 线，PAL APU 表。Dendy：1 CPU = 3 dots，312 线，NTSC APU 表，CPU 1.773447 MHz。
- **YM2413 在 `cart.Ym2413`**：log-sin+exp、ADSR、9 路+节奏；相位按 chip clock 走，18 slot × 4 = 72 clock 出一样。VRC7 只用 6 路和 Konami 音色。
- **不改 NES1 v2**：制式由 ROM 头在 `new Console` 时决定，不写入快照。

## 没选

- **单独 PAL 核 / 扫描线估帧**：不可逆成本是重写 PPU 与所有 mapper IRQ。
- **Host 切 50 Hz 墙钟**：有声卡时采样数已按 PAL CPU Hz 拉到约 50 帧；无声卡仍 60 Hz 限速（已知天花板）。
- **第三方 Nuked OPLL**：加依赖才能换一套表，当前标准库算得动。

## 后果

- 从此必须遵守：NTSC 盘不得走 3.2 比例；PAL 盘不得走 1:3；Dendy 不得走 3.2。
- 从此变贵的事：MMC5 扫描线 IRQ 要认 311 预渲染线。
- 推翻阈值：PAL 读档要对齐 3+3+3+3+4 相位（需 NES1 v3）；要 Nuked 级 18-slot 流水线再重开 YM2413。
